# คู่มือการทดสอบการใช้งานร่วมกับคุณครูจริง (User Testing Guide)
**โครงการ: ครูช่วยร่าง (KruChuai) - ผู้ช่วยครูลดงานเอกสารด้วย AI สำหรับโรงเรียนขนาดเล็ก**

---

## 1. วัตถุประสงค์การทดสอบ
เพื่อพิสูจน์สมมติฐานว่าแพลตฟอร์ม "ครูช่วยร่าง" สามารถ:
1. **ลดเวลา** ในการจัดทำแผนการสอนและสื่อใบงานได้อย่างน้อย 70%
2. **รองรับบริบทจริง** ของโรงเรียนขนาดเล็ก (การสอนควบชั้น / ขาดแคลนอินเทอร์เน็ต)
3. ผลิตเอกสารที่มี **ความถูกต้องทางวิชาการ** ตามหลักสูตรแกนกลาง สพฐ.

---

## 2. ขั้นตอนการทดสอบ (Testing Protocol)

### 🔹 ตอนที่ 1: การสัมภาษณ์ก่อนทดสอบ (Pre-test Interview: 10 นาที)
- ครูผู้สอน: .................................................... โรงเรียน: ....................................................
- วิชาที่สอน: .................................................. ระดับชั้น: ....................................................
- มีการสอนควบชั้นหรือไม่: [ ] มี  [ ] ไม่มี
- ปกติใช้เวลาเตรียมแผน/ใบงานต่อสัปดาห์: ................ ชั่วโมง
- ปัญหาที่พบในการเตรียมการสอน: ............................................................................

### 🔹 ตอนที่ 2: การทดสอบจับเวลา A/B Testing (Time Comparison: 30 นาที)
ให้คุณครูเลือกหัวข้อบทเรียนจริง 1 หัวข้อ (เช่น "เศษส่วนที่เท่ากัน" หรือ "ส่วนประกอบของพืช")
- **วิธี A (แบบเดิม):** ให้ครูเตรียมแผนและใบงานตามวิธีเดิม (ค้นหาเอง / พิมพ์เอง) ➔ **จับเวลา:** ............ นาที
- **วิธี B (ใช้ครูช่วยร่าง):** ให้ครูกรอกข้อมูลในแอป ปรับแก้ และกดดาวน์โหลด Word ➔ **จับเวลา:** ............ นาที
- **ผลต่างเวลาที่ประหยัดได้:** ............ นาที (คิดเป็น ............ %)

### 🔹 ตอนที่ 3: แบบประเมินความพึงพอใจหลังการใช้งาน (Post-test Usability: 1 - 5)

| ข้อที่ | ประเด็นการประเมิน | คะแนน (1-5) | ข้อเสนอแนะเพิ่มเติม |
|---|---|:---:|---|
| 1 | ความถูกต้องตามหลักวิชาการและตัวชี้วัด สพฐ. | | |
| 2 | ความเหมาะสมของใบงาน 3 ระดับ (พื้นฐาน/กลาง/ท้าทาย) | | |
| 3 | คำแนะนำและกิจกรรมในโหมดสอนควบชั้นใช้ได้จริง | | |
| 4 | กิจกรรมในโหมด Low-tech (ไร้เน็ต/ไร้จอ) ทำได้จริง | | |
| 5 | ความง่ายในการใช้งานระบบ (ไม่ซับซ้อน) | | |
| 6 | คุณภาพของไฟล์ Word (.docx) ที่ส่งออก | | |
| 7 | ความตั้งใจที่จะนำไปใช้งานจริงในภาคเรียนถัดไป | | |

*เกณฑ์คะแนน: 5 = ดีมาก/เห็นด้วยอย่างยิ่ง, 4 = ดี, 3 = ปานกลาง, 2 = พอใช้, 1 = ปรับปรุง*
