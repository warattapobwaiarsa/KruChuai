# คู่มือการใช้งานระบบ "ครูช่วยร่าง" (KruChuai User Guide)
## แพลตฟอร์ม AI ผู้ช่วยครูโรงเรียนขนาดเล็ก ร่างแผนการสอน ใบงาน 3 ระดับ และข้อสอบในคลิกเดียว

---

## 📌 1. บทนำ (Introduction)

**"ครูช่วยร่าง (KruChuai)"** พัฒนาขึ้นเพื่อแก้ปัญหาความเหลื่อมล้ำและลดภาระงานเอกสารของคุณครูใน**โรงเรียนขนาดเล็กของประเทศไทย** ซึ่งมักต้องเผชิญกับ:
1. **การสอนควบหลายระดับชั้น (Multi-Grade):** เช่น ครู 1 คนต้องสอนนักเรียน ป.3 และ ป.4 ในห้องเดียวกันพร้อมกัน
2. **ข้อจำกัดด้านอุปกรณ์และสัญญาณอินเทอร์เน็ต (Low-Tech / Limited Resources):** ในห้องเรียนไม่มีจอโปรเจกเตอร์หรือสัญญาณอินเทอร์เน็ตที่เสถียร ต้องพึ่งพากระดานดำ ชอล์ก และใบงานกระดาษ
3. **ภาระงานเอกสารซ้ำซ้อน:** ต้องจัดทำแผนการสอน 4 ขั้นตอนตามหลัก Active Learning, ใบงานแยกตามความสามารถ, แบบทดสอบ และ Rubric ประเมินผลส่งฝ่ายวิชาการทุกสัปดาห์

ระบบนี้ทำหน้าที่เป็น **"Human-in-the-Loop AI Assistant"** ที่ช่วยร่างโครงสร้างเอกสารราชการที่ถูกต้องตามหลักสูตรแกนกลาง สพฐ. 2551 ให้ครูตรวจสอบ ปรับแก้ และสั่งพิมพ์หรือดาวน์โหลด Word ไปใช้งานได้ทันทีในเวลาไม่เกิน 1 นาที

## 📖 3. ขั้นตอนการใช้งานระบบทีละขั้นตอน (Step-by-Step Tutorial)

### ขั้นตอนที่ 1: การใช้งานปุ่มลัด 1-Click Presets (สำหรับการสาธิตด่วน)
หากต้องการทดลองใช้งานทันทีโดยไม่ต้องกรอกข้อมูลเอง ให้คลิกปุ่มบนแถบ **1-Click Presets** ด้านบน:
1. 🏫 **สอนควบ ป.3 + ป.4 (เศษส่วน):** ระบบจะตั้งค่าวิชาคณิตศาสตร์ โหมดควบชั้น และดึงตัวชี้วัด ค 1.1 ป.4/1
2. 📶 **ไร้เน็ต/ไร้จอ (พืชรอบตัว ป.2):** ระบบจะตั้งค่าวิชาวิทยาศาสตร์ เปิดโหมด Low-tech ใช้วัสดุธรรมชาติรอบตัว
3. 📖 **อ่านเขียนเบื้องต้น (สระเสียงยาว ป.1):** ระบบจะตั้งค่าวิชาภาษาไทย เน้นการแจกลูกสะกดคำ

---

### ขั้นตอนที่ 2: การตั้งค่าห้องเรียนตามบริบทจริง
หากต้องการสร้างบทเรียนของตนเอง ให้กรอกข้อมูลในแผงควบคุมฝั่งซ้าย:
1. **เลือกกลุ่มสาระการเรียนรู้:** รองรับครบทั้ง 8 กลุ่มสาระของกระทรวงศึกษาธิการ
2. **เลือกระดับชั้นหลัก:** ป.1 ถึง ป.6
3. **เปิดโหมดสอนควบชั้น (Multi-Grade) [ถ้ามี]:** 
   - ติ๊กถูกที่ช่อง *โหมดสอนควบหลายชั้น*
   - เลือกชั้นเรียนที่นำมาควบสอนร่วม เช่น ป.4 ควบ ป.3
   - **ผลลัพธ์:** AI จะจัดตารางแบบสลับบทบาท เช่น ช่วงเวลาที่ครูอธิบายเนื้อหาใหม่ให้ชั้น ป.4 จะมอบหมายงานทบทวนให้ชั้น ป.3 สลับกัน เพื่อไม่ให้ห้องเรียนเกิด Dead-air
4. **ระบุหัวข้อบทเรียน:** พิมพ์ชื่อเรื่องที่ต้องการสอน เช่น *"การสังเคราะห์ด้วยแสง"*, *"มาตราตัวสะกดแม่เกย"*
5. **เลือกเวลาในการสอน:** เลือกปุ่มลัด `50 นาที`, `60 นาที` หรือ `100 นาที`
6. **เปิดโหมดอุปกรณ์และเน็ตจำกัด (Low-Tech) [ถ้ามี]:**
   - ติ๊กถูกที่ช่อง *โหมดอุปกรณ์และเน็ตจำกัด*
   - **ผลลัพธ์:** AI จะตัดการใช้โปรเจกเตอร์ สมาร์ตทีฟ หรือคลิป YouTube ออกทั้งหมด และปรับสื่อเป็นการใช้กระดานดำ ชอล์ก แถบประโยค หรือของจริงในท้องถิ่นแทน

### ขั้นตอนที่ 3: สั่งประมวลผลด้วย AI
- คลิกปุ่ม **"⚡ สั่งสร้างชุดเอกสาร AI (4-in-1 Suite)"**
- ระบบจะค้นหาตัวชี้วัด สพฐ. ที่ตรงกับหัวข้อผ่าน RAG Engine และประมวลผลผ่าน **Google Gemini 1.5 Flash** (ใช้เวลาประมาณ 3–8 วินาที)
- เอกสารทั้ง 4 ชนิดจะถูกสร้างขึ้นพร้อมกันในหน้าจอฝั่งขวา

---

### ขั้นตอนที่ 4: การตรวจดูและแก้ไขเอกสารใน Studio Canvas
เอกสารในฝั่งขวาถูกจัดวางในรูปแบบผืนกระดาษ A4 เสมือนจริง สามารถสลับดูได้ 4 แท็บ:

1. **📖 1. แผนการสอน (4 ขั้นตอน):**
   - มีแถบ **Visual Timeline** แสดงสัดส่วนเวลา 4 ขั้น (นำ 15% - สอน 35% - ปฏิบัติ 35% - สรุป 15%)
   - มีตารางแยกบทบาท **"ครู"** และ **"นักเรียน"** อย่างเป็นรูปธรรม
   - **คลิกพิมพ์แก้ไข:** สามารถคลิกที่ข้อความใดก็ได้บนหน้าจอเพื่อแก้ไข ปรับคำ หรือเพิ่มรายละเอียดตามต้องการ (WYSIWYG Inline Editing)

2. **📝 2. ใบงาน 3 ระดับ (Differentiated Worksheets):**
   - มีกรอบหัวกระดาษของนักเรียนสำหรับกรอกชื่อ ชั้น เลขที่ และคะแนน
   - จำแนกเป็น 3 การ์ดสีตามระดับความสามารถ:
     - 🟢 **ระดับ 1 (พื้นฐาน / Scaffolding):** มีตัวอย่าง มีการ์ดใบ้คำ เพื่อช่วยเด็กที่เรียนช้า
     - 🔵 **ระดับ 2 (ปานกลาง / Standard):** โจทย์แสดงวิธีคิดตามเกณฑ์ปกติของชั้นเรียน
     - 🟣 **ระดับ 3 (ท้าทาย / Advanced):** โจทย์ปัญหาเชื่อมโยงชีวิตประจำวัน พัฒนาทักษะคิดวิเคราะห์

3. **❓ 3. แบบทดสอบวัดผล (Interactive Quiz Station):**
   - แสดงข้อสอบปรนัย 4 ตัวเลือก พร้อมเฉลย
   - **Interactive Feature:** ครูหรือกรรมการสามารถคลิกปุ่มตัวเลือก ก, ข, ค, ง บนหน้าจอเพื่อทดสอบทำข้อสอบได้จริง โดยระบบจะเฉลยสีเขียว/แดง และแสดงคำอธิบายเหตุผลด้านล่างทันที

4. **📊 4. เกณฑ์การประเมิน (Scoring Rubric):**
   - ตารางเกณฑ์การให้คะแนน 4 ระดับ (ดีมาก, ดี, พอใช้, ปรับปรุง) ครอบคลุมทั้ง ด้านความรู้ (K), ด้านทักษะกระบวนการ (P), และคุณลักษณะอันพึงประสงค์ (A)

### ขั้นตอนที่ 5: การบันทึกและจัดการคลังแผนการสอน (My Library)
- **บันทึกแผน:** คลิกปุ่ม **"💾 บันทึกแผน"** ที่แถบเมนูด้านบน ข้อมูลทั้งหมดจะถูกบันทึกลงสู่ฐานข้อมูลจริง
- **เปิดดูคลังแผน:** คลิกปุ่ม **"📚 คลังแผนของฉัน"** จะมีหน้าต่าง Pop-up แสดงรายการแผนการสอนทั้งหมดที่เคยบันทึกไว้ สามารถคลิกปุ่ม **"เปิดแผนนี้"** เพื่อดึงกลับมาแสดงผลและแก้ไขต่อได้ในคลิกเดียว

### ขั้นตอนที่ 6: การส่งออกไฟล์เอกสารราชการ
- **ดาวน์โหลดไฟล์ Word (.docx):** คลิกปุ่ม **"📥 ดาวน์โหลด Word"** ระบบจะคอมไพล์เอกสารทั้งหมดเป็นไฟล์ `.docx` จัดรูปแบบตามระเบียบสารบรรณ ฟอนต์ TH Sarabun PSK ขนาดมาตรฐาน ตารางและระยะกั้นหน้า 1 นิ้ว พร้อมส่งผู้บริหารสถานศึกษา
- **สั่งพิมพ์ (Print-to-A4):** คลิกปุ่ม **"🖨️ พิมพ์ A4"** ระบบจะเรียกหน้าต่าง Print ของระบบปฏิบัติการ โดยมี CSS Print Media ซ่อนเมนูและปุ่มควบคุมทั้งหมด เหลือเฉพาะเนื้อหาเอกสารราชการที่พร้อมสั่งพิมพ์ออกเครื่องพิมพ์ได้ทันที

## ⚙️ 4. การตั้งค่า AI Engine & API Key

ระบบออกแบบมาให้ยืดหยุ่นสูงสุด 3 รูปแบบ:
1. **Google Gemini 1.5 Flash (Default Cloud Key):** ตั้งค่าผ่านตัวแปร `GEMINI_API_KEY` ในไฟล์ `.env` ของระบบ
2. **Custom API Key ผ่านหน้าเว็บ:** คลิกปุ่ม **"⚙️ AI API"** บนแถบเมนู เพื่อนำ Gemini API Key ส่วนตัวมาวางในเบราว์เซอร์ได้ทันที
3. **Heuristic Offline Fallback:** หากไม่มีการใส่ Key หรือในกรณีที่โรงเรียนไม่มีอินเทอร์เน็ต ระบบจะสลับไปใช้ Heuristic Rule-Based Engine อัตโนมัติ เพื่อให้ครูยังคงได้โครงสร้างแผนการสอนที่สมบูรณ์ 100% โดยระบบไม่ล่ม

## ❓ 5. คำถามที่พบบ่อย (FAQ)

**Q: ข้อมูลนักเรียนจะหลุดออกไปหรือไม่? มีปัญหา PDPA ไหม?**  
*A: ระบบไม่มีการขอหรือจัดเก็บข้อมูลส่วนบุคคลของนักเรียน (Zero Student PII) ในทุกกรณี มีเพียงการระบุระดับชั้นและจำนวนเวลาเท่านั้น จึงปลอดภัยตาม พ.ร.บ. คุ้มครองข้อมูลส่วนบุคคล 100%*

**Q: หากเปิดใช้ในโรงเรียนที่เน็ตช้ามากๆ จะใช้งานได้ไหม?**  
*A: ได้ครับ ตัว Frontend มีขนาดเบามาก และมีไฟล์ `index.html` สำรองที่สามารถเปิดใช้งานแบบ Standalone ได้โดยไม่ต้องพึ่งพาเซิร์ฟเวอร์ภายนอก*

**Q: ไฟล์ Word ที่ได้ ต้องนำไปจัดหน้าใหม่หรือไม่?**  
*A: ไม่ต้องครับ ระบบ Backend ใช้ไลบรารี `python-docx` ในการกำหนดระยะขอบ A4 กั้นหน้า 1 นิ้ว กั้นหลัง 1 นิ้ว และใช้ตารางสารบรรณภาษาไทยที่พร้อมลงนามส่ง ผอ. ได้ทันที*
